Ecco la nostra roadmap di sviluppo:

Fase 1: Le Fondamenta (Ambiente virtuale, Git, Flask base).

Fase 2: Il Motore Dati (Progettazione schema SQLite e funzioni CRUD pure in Python).

Fase 3: Il Ponte Backend (Rotte Flask e integrazione DB).

Fase 4: L'Interfaccia (Motore di template Jinja, HTML, CSS).

Fase 5: Il Dinamismo (JavaScript, API RESTful, manipolazione DOM).

Fase 6: Il Lancio (Configurazione e deploy su VPS).

Mettiamo subito le mani in pasta con la Fase 1. Apri il terminale e completa questo primo task operativo:

Crea una cartella per il progetto (es. frigo_app) ed entraci.

Inizializza il repository locale (git init).

Crea e attiva il tuo ambiente virtuale isolato (python -m venv venv).

Installa il framework (pip install flask).

Crea un file app.py puro ed essenziale: deve solo importare Flask, avere una singola rotta / e restituire a schermo la stringa "Il frigo è acceso!".
